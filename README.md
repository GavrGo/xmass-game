# Drift Boss — 5 моделей машин

## Что внутри

Папка `files/` — готовые файлы, которые нужно положить в проект поверх текущих:

```
files/src/game/carModels.ts     (НОВЫЙ файл — сами модели)
files/src/game/driftBoss.ts     (правка: поле model, ротация в createGame)
files/src/screens/DriftBoss.tsx (правка: отрисовка выбранной модели + переключение при старте)
```

`drift-cars.patch` — тот же диффом (git apply), если удобнее применять патчем.

`preview/lineup-5cars.jpg` — как выглядят все 5 моделей спереди / сбоку / сзади.

## Модели

1. `stock` — базовая машина (как была)
2. `muscle` — маслкар, длинный капот, широкий кузов
3. `supercar` — низкий суперкар в стиле Lamborghini
4. `tuned` — седан с большим антикрылом и обвесом
5. `suv` — Range Rover: высокий прямоугольный кузов, плоская крыша

Габарит у всех одинаковый: `|a| ≤ 20.5`, `|b| ≤ 10.5`, колёса на `a = ±12`.
Поэтому хитбокс, посадка на дорогу и коллизии не меняются — модели чисто визуальные.

## Ротация и цвет

- **Ротация:** при каждом новом заезде модель берётся по кругу (`модельRef` в `DriftBoss.tsx`, перед `createGame`).
- **Цвет:** остаётся случайным из 8 палитр (`paint: Math.floor(Math.random() * 8)` в `createGame`), то есть каждая новая машина и нового цвета.
